# 2D 平台跳跃游戏练习项目

> 基于 Godot 4 + C# 的 2D 平台跳跃动作游戏。  
> 这是跟随 Godot 教程完成的学习项目，核心逻辑使用 C# 重写。

---

##  项目说明

这是一个用于学习和练习 Godot 游戏开发的 2D 平台跳跃项目。

- 项目主体框架参考了 Godot 2D 平台跳跃教程
- 将原教程的 GDScript 代码用 **C#** 重新实现
- 在完成教程内容的基础上，对部分参数和逻辑做了个性化调整
- 项目目标：熟悉 Godot 4 的 2D 游戏开发流程、状态机设计、碰撞检测与 UI 交互

---

##  核心功能

- 角色基础移动（跑、跳、二段跳、攀墙）
- 简单的战斗系统（攻击、受击、击退）
- 状态机驱动的角色行为控制
- 基础 UI（血量显示、交互提示）
- 场景切换与传送门
- 存档与读档
- 音量设置
- **虚拟摇杆（移动端适配）**

## 视觉与反馈

- 摄像机震屏反馈（受伤、攻击命中时触发）
- 简单的景深效果

##  如何运行

1. 下载 Godot 4.6.1（.NET 版本）
2. 克隆本仓库
3. 用 Godot 打开项目文件夹
4. 运行主场景

##  操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 跳跃 |
| J | 攻击 |
| Shift | 滑铲 |
| ESC | 暂停 |
